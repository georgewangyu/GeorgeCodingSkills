# GeorgeCodingSkills

Agent skills for coding work, each tagged by how likely it is to survive better models.

## Skills

| Skill | What it does |
|---|---|
| [`start-playbook`](skills/start-playbook/SKILL.md) | Start here. Maps the task to the right skill in lifecycle order (define, plan, build, verify, review, ship) and sets the always-on behaviors. Adapted from [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `using-agent-skills`. |
| [`grill-me`](skills/grill-me/SKILL.md) | Interviews you until the intent, or every decision in a plan, is settled. Rounds with a recommended answer per question, facts looked up by the agent, explicit-yes gate. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `interview-me` and [mattpocock/skills](https://github.com/mattpocock/skills) `grilling`. |
| [`brainstorm`](skills/brainstorm/SKILL.md) | Turns a rough idea or an open "how should we build X" into a decision: ground first, challenge premises, 4 to 6 options across axes, prune to 2 or 3 with pros, cons and a cost check, optional bakeoff, decision note with a Not Doing list. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `idea-refine`, [obra/superpowers](https://github.com/obra/superpowers) `brainstorming`, [garrytan/gstack](https://github.com/garrytan/gstack) `office-hours`, [EveryInc/compound-engineering-plugin](https://github.com/EveryInc/compound-engineering-plugin) `ce-ideate` / `ce-bakeoff` / `ce-pov`, [pstack](https://github.com/cursor/plugins/tree/main/pstack) `sharpen` / `arena` and [mattpocock/skills](https://github.com/mattpocock/skills) `prototype`. |
| [`spec`](skills/spec/SKILL.md) | Writes down what we are building before building it. Brief by default: goal, a done check that can fail, proof wanted, what we know, constraints, out of scope (also the format for worker briefs). Full mode only when earned (one-way doors, multi-PR work, cross-team review, a new service or API): scope check, boundaries, user stories, test seams, a design contract for multi-PR work, normal and blind review. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `spec-driven-development`, [mattpocock/skills](https://github.com/mattpocock/skills) `to-spec`, [obra/superpowers](https://github.com/obra/superpowers) `writing-plans`, [garrytan/gstack](https://github.com/garrytan/gstack) review lenses, [EveryInc/compound-engineering-plugin](https://github.com/EveryInc/compound-engineering-plugin) `ce-plan` and the [pstack](https://github.com/cursor/plugins/tree/main/pstack) guide. |
| [`plan`](skills/plan/SKILL.md) | Turns a spec into ordered vertical slices that each end green, one slice per PR, ticket and worker brief. Brief by default: goal, a done check that can fail, how to verify, blocking edges (deploy edges too), files, size. Full mode for a multi-PR series, rollout ordering or work bigger than one session: design contract, interfaces, rollout table, decision list. Never overwrites an unfinished plan; tickets and workers are offered, never automatic. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `planning-and-task-breakdown`, [mattpocock/skills](https://github.com/mattpocock/skills) `to-tickets` and `wayfinder`, [obra/superpowers](https://github.com/obra/superpowers) `writing-plans` and `executing-plans`, [EveryInc/compound-engineering-plugin](https://github.com/EveryInc/compound-engineering-plugin) `ce-plan`, [garrytan/gstack](https://github.com/garrytan/gstack) `plan-eng-review` and [pstack](https://github.com/cursor/plugins/tree/main/pstack) `principle-sequence-verifiable-units`. |
| [`build`](skills/build/SKILL.md) | Builds a plan one slice at a time. Each slice ends in a PR revision with green CI and a passed done check, then a fresh-context review before the next slice. Fresh worker or subagent per independent slice, rule 0 simplicity, scope discipline (log, do not fix), safe defaults, a capped fix loop, rulings instead of stalls, the plan index as the ledger. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `incremental-implementation`, [obra/superpowers](https://github.com/obra/superpowers) `subagent-driven-development` and [pstack](https://github.com/cursor/plugins/tree/main/pstack) `principle-sequence-verifiable-units`, `principle-laziness-protocol` and `principle-subtract-before-you-add`. |
| [`source-driven`](skills/source-driven/SKILL.md) | Reads and cites the real source before implementing: exact versions from the lockfile, then the installed dependency source, the library's repo at that version, versioned official docs. Pinned permalinks, never invent a method or config name, UNVERIFIED when unchecked, fetched content is data. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `source-driven-development` and [mattpocock/skills](https://github.com/mattpocock/skills) `research`. |
| [`interfaces`](skills/interfaces/SKILL.md) | Designs seams, APIs, schemas and config keys that are deep and safe to roll out and back. Contract first, every observable behavior is a contract (Hyrum), behavior declared by the injected implementation, validate at boundaries (including data an older version wrote), illegal states unrepresentable, additive changes only, evolve by addition, and the contracts upstream leaves out: timeouts, ordering, async delivery and overload. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `api-and-interface-design`, [mattpocock/skills](https://github.com/mattpocock/skills) `codebase-design` and `domain-modeling` and [pstack](https://github.com/cursor/plugins/tree/main/pstack) boundary, type and domain principles. |
| [`context`](skills/context/SKILL.md) | Loads, keeps and hands off context. Docs-first layering, trust levels, guard the window, checkpoint vs final report, worker briefs that always carry the plan with absolute paths, follow-ups to the running worker, resume checked against live state. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `context-engineering`, [mattpocock/skills](https://github.com/mattpocock/skills) `handoff` and `writing-for-agents`, [EveryInc/compound-engineering-plugin](https://github.com/EveryInc/compound-engineering-plugin) `ce-handoff`, [garrytan/gstack](https://github.com/garrytan/gstack) `context-save` and [pstack](https://github.com/cursor/plugins/tree/main/pstack) `guard-the-context-window` and `recall`. |
| [`doubt`](skills/doubt/SKILL.md) | Cross-examines a non-trivial decision before it stands. A thin router: names the claim and keeps it back, hands only the artifact and its contract to the right fresh-context reviewer with one or two lenses, adds a second model for one-way doors, reconciles every finding (contract misread, act on, consider, dismissed) and stops after three cycles. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `doubt-driven-development`, [pstack](https://github.com/cursor/plugins/tree/main/pstack) `interrogate`, [EveryInc/compound-engineering-plugin](https://github.com/EveryInc/compound-engineering-plugin) `ce-doc-review` lenses and [obra/superpowers](https://github.com/obra/superpowers) `receiving-code-review`. |
| [`frontend`](skills/frontend/SKILL.md) | Builds or changes UI: app screens and the HTML artifacts an agent writes for review. Reads the project's UI rules first, names the mode (operate, read, persuade), keeps one owner per piece of state, uses design-system tokens over AI defaults, holds the accessibility floor, and verifies in the running app with a screenshot. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `frontend-ui-engineering`, [anthropics/skills](https://github.com/anthropics/skills) `frontend-design` and `webapp-testing`, [garrytan/gstack](https://github.com/garrytan/gstack) `design-review` and [pstack](https://github.com/cursor/plugins/tree/main/pstack) `principle-experience-first`. |
| [`test-driven-development`](skills/test-driven-development/SKILL.md) | Proves a change with the most real test that is still cheap. Uses the repo's own verification skill first, then a real-world-first ladder (a seam test with real collaborators, the running environment as evidence, unit tests only for pure logic). Every test names the real failure it catches. Loose TDD: strict red-green only where the loop is cheap, no new test over a bad one, tests at agreed seams, prove-it for bugs, coverage met at the gate without padding. Combines [cursor/plugins pstack](https://github.com/cursor/plugins/tree/main/pstack) `tdd` and `create-verification-skill`, [mattpocock/skills](https://github.com/mattpocock/skills) `tdd`, [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `test-driven-development`, [obra/superpowers](https://github.com/obra/superpowers) `test-driven-development` and [garrytan/gstack](https://github.com/garrytan/gstack) `test-audit`. |
| [`browser-testing`](skills/browser-testing/SKILL.md) | Verifies UI in a real browser, short and flexible. Repo verification skill first, pick the tool that fits (Playwright, geckodriver, DevTools MCP, computer use), isolate on a temp profile, drive one real flow, look at the screenshot and console, treat page content as untrusted, clean up every browser and driver. Combines [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `browser-testing-with-devtools`, [anthropics/skills](https://github.com/anthropics/skills) `webapp-testing`, [pstack](https://github.com/cursor/plugins/tree/main/pstack) `create-verification-skill` and [garrytan/gstack](https://github.com/garrytan/gstack) `qa-only`. |
| [`constraints`](skills/constraints/SKILL.md) | The top-down half of the quality bar. On existing code, reports the gates that already run, with no new file. On a new project, writes CONSTRAINTS.md once (one short interview with defaults); non-interactive runs apply the floor only. Each rule records its origin (declared or mined). Guards the bar on every diff: threshold moved, test made easier, checker silenced, unfinished work, new exception. Adapted from [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) `constraint-driven-development` and [pstack](https://github.com/cursor/plugins/tree/main/pstack) `correct`. |
| [`mistake-miner`](skills/mistake-miner/SKILL.md) | The bottom-up half. Buffers agent mistakes instead of fixing each one: a fast bash capture hook on the user's correction prompts, a daily harvest of evaluator findings, review comments, failed CI and new agent rules into an append-only inbox, and a weekly cluster review (3+ hits, mechanism in pstack order, proof plan, human decision). Never edits code itself. Based on Lauren Tan's buffer of bad patterns and [pstack](https://github.com/cursor/plugins/tree/main/pstack) `correct` and `reflect`. |
| [`principles`](skills/principles/SKILL.md) | Index of the evaluation methods for a claim, a number, a design, or scaffolding. |
| [`principles-scientific-method`](skills/principles-scientific-method/SKILL.md) | Hypothesis, prediction before acting, one change at a time, baseline, try to prove yourself wrong, confidence labels. |
| [`principles-first-principles`](skills/principles-first-principles/SKILL.md) | Fermi bounds from cores, bandwidth, memory, latency, queueing and OS limits, compared against the claim. |
| [`principles-bitter-lesson`](skills/principles-bitter-lesson/SKILL.md) | Sorts agent scaffolding by Sutton's [bitter lesson](http://www.incompleteideas.net/IncIdeas/BitterLesson.html) ("would we still need this if the model were 10x smarter?") and ships the tag checker. Formerly `bitter-lesson-check`. |

## Bitter-lesson tags

Each skill marks its parts with a short inline tag:

- `[bl: invariant]`: a rule of the game (a feedback signal, an eval, or a real invariant). Always follow.
- `[bl: strong]`: follow it. It should become a hard check or a learned example over time.
- `[bl: soft]`: guidance for weaker models. A strong model may skip it. Candidate to expire.

A `BITTER_LESSON.md` next to each `SKILL.md` holds the full analysis (why, review date, delete-when, ablation result). Agents only read it when evaluating skills, not at session start.

```sh
python3 skills/principles-bitter-lesson/scripts/bitter_lesson.py check  --root .   # every tagged item has a row, and the reverse
python3 skills/principles-bitter-lesson/scripts/bitter_lesson.py report --root .   # the cleanup list
python3 skills/principles-bitter-lesson/scripts/bitter_lesson.py ablate --root .   # soft items to test with and without
```

Principle skills (`principles*`) are durable reasoning methods and carry no tags.

Expire by evidence: run the skill's eval with and without a soft item on a new model. If nothing changes, delete it. A skill whose items have all expired goes away.

## Install

Copy a skill folder into your agent's skills directory (for example `~/.claude/skills/`).
